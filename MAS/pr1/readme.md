# Expectation Decider

## Project Objective
A predictive model that estimates whether a student will **pass or fail** a competitive mathematics exam, based on historical academic and behavioral data.

## Dataset
File: `students.csv` (200 students)

| Field | Description |
|---|---|
| `study_hours` | Number of hours a student studied per week |
| `attendance` | Percentage attendance in lectures |
| `group_discussion` | Participation in group discussions (Yes/No) |
| `previous_test_score` | Marks out of 100 from the last internal test |
| `final_exam_pass` | Whether the student passed the competitive exam (Pass/Fail) |

## Tasks Covered
1. Basics of Probability & Key Terminology
2. Empirical vs Theoretical Probability
3. Random Variable & Probability Distribution (Mean & Variance)
4. Venn Diagram (Study Hours vs Attendance)
5. Contingency Table & Probability Calculations
6. Conditional Probability & Independence Check
7. Bayes' Theorem Application
8. Final Summary of Key Factors Affecting Pass Probability

## Tools Used

- Pandas / NumPy
